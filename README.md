# 10X Living app

A small website for a well-being culture (Medicina in Guanacaste, and groups of 30–150 people anywhere).

**It is not trying to make money. It is not trying to keep you here.**
It is trying to help people live together with a fence (no harm) and no parent (no lifestyle police).

## Pages
- Home — what this is
- Join — watch a video, then a form (same idea as the Jotform on 10xliving.org)
- Constitution — the fence you sign
- Check-in — one feeling now, then a suggestion to go do something in the world
- Roles — the 4-4-4 day (earn / community / life)

## How to look at it on your computer
1. Download this project (the green Code button → Download ZIP, then unzip).
2. Double-click `index.html`.
3. It opens in your browser. No install.

Optional: GitHub can also host it as a free webpage (Settings → Pages → Deploy from main).
