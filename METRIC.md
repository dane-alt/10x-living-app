# The only metric

Intelligence = energy converted into sustainable well-being.

This app is scored by **well-being generated per minute of human attention**.

Forbidden optimizations:
- time on site
- daily active users as a goal
- ads, upsells, streaks that shame, infinite feeds, nag notifications

A session that ends with a walk, a meal, a conversation, or rest is a success.
A session that keeps someone tapping is a failure.

If you are contributing code and your change would increase time-on-app without
increasing life-off-app, do not merge it.
